# Source Cores

Reusable seeds injected with provider manifests:

- **webcore** — WebView/session protocol transport
- **apicore** — HTTP API (OpenAI-compatible, Anthropic, Gemini, …)
- **mcpcore** — MCP tool servers (policy-gated in OmniHub)

Provider-specific APKs = seed + manifest, not 1000 unique codebases.
